
# Trinetra Backend
AI-powered surveillance backend

## Quick Start
1. Install dependencies: `uv pip install -e .`
2. Configure `.env` (copy from `.env.example`)
3. Run server: `uv run uvicorn app.main:app --reload`
4. Visit API docs: http://127.0.0.1:8000/docs

For full documentation, see [DOCUMENTATION.md](../DOCUMENTATION.md) in the project root.
